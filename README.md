# بوابة دفعة 32 — Next.js + Supabase (نسخة الإنتاج الحقيقية)

كود حقيقي قابل للنشر، ببنية Next.js 15 + TypeScript + Tailwind + Supabase.
قاعدة بيانات حقيقية مشتركة، تسجيل دخول حقيقي لكل عضو بحسابه الخاص، ونظام صلاحيات متدرّج (صلاحية كاملة / صلاحية محدّدة حسب اللجنة).

## نظام الصلاحيات

- **صلاحية كاملة** (الأمين العام ورئيس الدفعة): وصول لكل أقسام لوحة التحكم بما فيها إدارة الفريق والإعدادات العامة.
- **رئيس لجنة**: يشوف فقط الأقسام اللي اتحددت له (مثلًا: الإعلامية → الأخبار + أرشيف الذكريات، العلمية → المواد الدراسية). تحدَّد هذي الصلاحيات من صفحة "الفريق والصلاحيات" داخل لوحة التحكم نفسها.
- كل عضو له بريد وكلمة مرور خاصين به — ما فيه حساب أدمن مشترك.
- رابط لوحة التحكم (`/admin`) مو ظاهر في أي مكان بالموقع العام — يوصل بس اللي عنده الرابط مباشرة.

## 1) إعداد مشروع Supabase (~10 دقائق)

1. أنشئ مشروع جديد على [supabase.com](https://supabase.com).
2. من **SQL Editor**، شغّل الملفين بالترتيب:
   - `supabase/migrations/0001_init.sql`
   - `supabase/migrations/0002_roles_and_permissions.sql`
   - `supabase/migrations/0003_external_links.sql`
   - `supabase/migrations/0004_featured_flags.sql`
3. من **Authentication → Users → Add user**، أضف حسابك أنت (بريد وكلمة مرور).
4. من **Table Editor → profiles**، لاقي صفّك وغيّر `role` من `student` إلى `super_admin` يدويًا. هذي الخطوة اليدوية الوحيدة — أي حساب تضيفه بعد كده يصير من داخل لوحة التحكم مباشرة (صفحة "الفريق والصلاحيات") من غير لمس قاعدة البيانات.
5. من **Project Settings → API**، خذ نسخة من:
   - `Project URL`
   - `anon public` key
   - `service_role` key (سرّي — يُستخدم فقط لإنشاء حسابات أعضاء الفريق، ما يوصل المتصفح أبدًا)

## 2) التشغيل محليًا

```bash
cp .env.local.example .env.local
# عبّي القيم الثلاث من الخطوة 5 فوق

npm install
npm run dev
```

`http://localhost:3000` للموقع العام، و`http://localhost:3000/admin` للوحة التحكم — سجّل دخول بالحساب اللي رقّيته لـ super_admin.

من صفحة "الفريق والصلاحيات"، أضف باقي رؤساء اللجان: اسم، بريد، كلمة مرور (تولّد تلقائيًا وتقدر تعدّلها)، ثم حدد له صلاحية كاملة أو رئيس لجنة + الأقسام اللي يديرها. بعد الحفظ، انسخ بيانات الدخول وشاركها معاه مباشرة.

## 3) اللوقو

الشعارات الثلاثة متضمّنة بالفعل في `public/`: `logo-batch32.png`، `logo-fcsit.png`، `logo-aau.png`. ما فيه شي ناقص هنا.

## 4) النشر (Vercel)

1. ارفع المجلد على GitHub.
2. من [vercel.com](https://vercel.com)، "New Project" واختر الـ repo.
3. أضف نفس المتغيرات الثلاث من `.env.local` في إعدادات Environment Variables — بما فيها `SUPABASE_SERVICE_ROLE_KEY` (تأكد إنه مو محدد كـ "Public").
4. Deploy.

## شنو جاهز الحين

- البنية التحتية كاملة: قاعدة البيانات، تخزين الملفات، مصادقة حقيقية، نظام صلاحيات متدرّج بثلاث طبقات (RLS على مستوى قاعدة البيانات + فحص على مستوى كل Server Action + إخفاء الأقسام غير المسموحة في الواجهة).
- تسجيل دخول/خروج حقيقي، وصفحة "الفريق والصلاحيات" لإنشاء وإدارة حسابات الأعضاء.
- رابط لوحة التحكم غير ظاهر بالموقع العام.
- اللوقو الجديد مطبّق (مع خلفية بيضاء خفيفة خلفه بالوضع الليلي، لأن الرقم "3" غامق جدًا ليكون واضح على خلفية داكنة مباشرة).
- الموقع يفتح دائمًا بالوضع النهاري افتراضيًا، والتبديل بين الفاتح والداكن أصبح داخل قائمة البيرغر فقط (بكل أحجام الشاشات).
- كل الأقسام جاهزة 100% (عام + لوحة تحكم مقيّدة بالصلاحية المناسبة): الأخبار، المواد الدراسية (مع الملفات والملخصات والروابط والواجبات)، مشاريع الطلاب، أرشيف الذكريات، اللجنة التنفيذية، تواصل معنا، إعدادات الموقع.
- ملفات المواد والملخصات تقبل إما رفع مباشر (Supabase Storage) أو رابط خارجي (قوقل درايف مثلًا) — مفيد للملفات الكبيرة عشان ما تستهلك حصة التخزين المجانية بسرعة.
- الشعارات الثلاثة (الدفعة، الكلية، الجامعة) مرفوعة وشغالة في الفوتر.
- الأخبار، مشاريع الطلاب، وأرشيف الذكريات — كل واحد فيها فيه خيار "تثبيت/تمييز" (⭐) يتحكم في: (1) ترتيب الظهور في صفحته الكاملة، و(2) هل يظهر في معاينة الواجهة الرئيسية أو لا. أرشيف الذكريات تحديدًا ما كان له أي ظهور بالرئيسية قبل كده — أضفت قسم كامل له.

## شنو تصلّح في هذا التحديث

راجعت المشروع بالكامل وطلعت ثغرتين حقيقيتين:
1. **قسم "التقويم"** كان ظاهر بقائمة لوحة التحكم لكن صفحته مو موجودة فعليًا (404). اتصلّحت، وتأكدت آليًا إن كل رابط بالموقع (عام وإداري) يوصل لصفحة موجودة فعليًا.
2. **تثبيت الأخبار ما كان يؤثر على الواجهة الرئيسية** — كان يرتّب بس داخل صفحة "الأخبار" نفسها، مو المعاينة اللي بالرئيسية. اتصلّح، ونفس الفكرة (تمييز ⭐) اتضافت لمشاريع الطلاب وأرشيف الذكريات كمان، بما إنها ما كانت موجودة أصلًا.

وأضفت **إعادة تعيين كلمة مرور** لأي عضو من صفحة "الفريق" — قبل كده لو حد نسى كلمة المرور ما كان فيه طريقة يسترجعها.

## اللي لسه محتاج انتباهك (مو أخطاء، بس نواقص محتوى/إعداد)

- الأقسام غير الأخبار فاضية لحد ما تضيف محتوى فعلي من لوحة التحكم — هذا متوقع، مو خلل.
- ما فيه صفحة "نسيت كلمة المرور" ذاتية للأعضاء أنفسهم — الاسترجاع الوحيد حاليًا هو إن صاحب الصلاحية الكاملة يعيد التعيين له يدويًا من صفحة الفريق. لو تحبه تلقائي عبر بريد إلكتروني، قولّي.
- صور أرشيف الذكريات (الألبومات) ما فيها حقل نص/تعليق لكل صورة — بس عنوان قصير للألبوم نفسه. لو تحب تضيف وصف نصي لكل صورة على حدة، قولّي.

قولّي "كمل" لما تكون جاهز أكمل الباقي.
