# 🎓 بوابة دفعة 32 — Batch 32 Portal

منصة إلكترونية متكاملة لإدارة ومشاركة محتوى الدفعة، مبنية باستخدام **Next.js 15** و **Supabase** مع دعم كامل لنظام مصادقة وصلاحيات متدرج.

---

## 🔐 نظام الصلاحيات وإدارة الوصول

تتضمن المنصة نظام صلاحيات دقيق لإدارة المحتوى وفق الهيكل التنظيمي للدفعة:

* **صلاحية كاملة (Super Admin):** مخصصة للرئاسة العامة والأمانة العامة للوصول الشامل للوحة التحكم، إدارة الفريق، والتكوين العام.
* **رئيس لجنة (Committee Leader):** صلاحيات مخصصة للأقسام التابعة له فقط (مثل: *اللجنة الإعلامية* ← الأخبار وأرشيف الذكريات، *اللجنة العلمية* ← المواد الدراسية). يتم تعيين الأذونات من صفحة "الفريق والصلاحيات".
* **حسابات فردية مستقلة:** يتوفر لكل عضو حساب خاص (بريد إلكتروني وكلمة مرور) دون الاعتماد على حسابات أدمن مشتركة.
* **عزل لوحة التحكم:** مسار اللوحة (`/admin`) محمي ومخفي بالكامل عن الواجهة العامة للموقع.

---

## 🚀 دليل التهيئة والإعداد (Supabase Setup)

### 1. إعداد قاعدة البيانات والمصادقة

1. أنشئ مشروعاً جديداً عبر منصة [Supabase](https://supabase.com).
2. افتح **SQL Editor** ونفّذ ملفات التهيئة بالترتيب التالي:
   * `supabase/migrations/0001_init.sql`
   * `supabase/migrations/0002_roles_and_permissions.sql`
   * `supabase/migrations/0003_external_links.sql`
   * `supabase/migrations/0004_featured_flags.sql`
3. قم بإنشاء حسابك الأساسي من **Authentication ← Users ← Add user**.
4. انتقل إلى **Table Editor ← profiles** وقم بترقية دور حسابك بتغيير قيمة `role` من `student` إلى `super_admin`. *(تتم إضافة بقية الأعضاء لاحقاً مباشرة من لوحة التحكم)*.
5. استخرج بيانات الاتصال التالية من **Project Settings ← API**:
   * `Project URL`
   * `anon` (Public API Key)
   * `service_role` (Secret Key)
